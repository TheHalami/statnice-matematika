# Mathematics state-exam study materials

Czech study materials organized around **40 mathematics topics** for primary-school teacher training at PdF MUNI. The material is intended for students studying mathematics as either their main or secondary teaching subject.

**[Open the study site](https://thehalami.github.io/statnice-matematika/)**

## Repository

- `index.html` contains the published study resource.
- Open the published site to browse the material; no account is required.
- To inspect or adapt the source, download the repository and open `index.html` in a modern browser.

## Project context

Created as a personal study tool by Jakub Halamásek, using AI-assisted development and content workflows. The project demonstrates organizing a large body of subject matter into a navigable resource and maintaining consistent Czech terminology.

This is a personal learning resource, not an official Masaryk University publication. Check important results and definitions against your course materials; repository availability is not a guarantee of factual completeness or correctness.
